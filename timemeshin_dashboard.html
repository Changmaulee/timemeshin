🔒 100% Local-First
⏱️ Level 1: Telemetry & App Focus
CPU: < 0.1% 💾 24h Max: ~10 KB – 25 KB 🔒 Ultra-Private Metadata
🔍 What Is Captured:
• Active window titles & process executables (via native Win32/ctypes).
• Foreground task start/end timestamps and dwell time.
• User idle status detection (>3 minutes inactive).
🛡️ Privacy & 24h Storage Footprint:
• Zero content capture: No keystrokes, no file contents, no screenshots.
• Worst-Case 24h Storage: ~10 KB to 25 KB / day (compressed SQLite WAL tuples).
💬 Level 2: Narrative & Episodic Surface
CPU: ~0.2% 💾 24h Max: ~120 KB – 350 KB 🔒 Episodic Prompts & Form State
🔍 What Is Captured:
• AI Chat conversations (prompts & outputs) across Gemini Web, ChatGPT, Claude.
• Doctor Strange Time Stone: Closed tab URLs & form inputs (auto-restorable).
• Mobile speech-to-text voice memos and thoughts.
🛡️ Privacy & 24h Storage Footprint:
• Saves unstructured thoughts and conversational context with password fields excluded.
• Worst-Case 24h Storage: ~120 KB to 350 KB / day (stores ~100 dense AI prompts & tab states).
🧬 Level 3: AST & Code Mutation Lineage
CPU: ~0.5% 💾 24h Max: ~1.5 MB – 4.5 MB 🔒 Code Structural Diffs
🔍 What Is Captured:
• Python AST syntax trees on file save (classes, functions, method arguments).
• Myers structural diffs between code revisions.
• ShowLLM Cartridge Foundry: Compiles standalone Movie-Codec knowledge cartridges (.json).
🛡️ Privacy & 24h Storage Footprint:
• Tracks structural code mutations without copying duplicate whole files or .env secrets.
• Worst-Case 24h Storage: ~1.5 MB to 4.5 MB / day (~300 file saves). ShowLLM Cartridge: ~500 KB.
⚙️ Level 4: OS Kernel & File I/O Tracing
CPU: ~1.0% 💾 24h Max: ~8 MB – 20 MB 🔒 File Paths & Exit Codes
🔍 What Is Captured:
• Real-time file system mutations (created, modified, deleted) via FileSystemWatcher.
• Terminal and subprocess execution status, commands, and exit codes.
• Causal linking between build/compiler failures and recent code edits.
🛡️ Privacy & 24h Storage Footprint:
• Monitors project directory I/O paths and execution status codes.
• Worst-Case 24h Storage: ~8 MB to 20 MB / day (captures ~15,000 build/npm events & build logs).
👁️ Level 5: Multimodal Sensory Memory
CPU: ~2.5% 💾 24h Max: ~85 MB – 180 MB 🔒 Local Perceptual Buffers
🔍 What Is Captured:
• Perceptual visual keyframe thumbnails (pHash) on visual scene shifts.
• On-device OCR screen text extraction for non-text windows (diagrams, IDE popups).
• Spoken audio speech transcription buffers.
🛡️ Privacy & 24h Storage Footprint:
• 100% On-Device: Visual and acoustic buffers remain local.
• Worst-Case 24h Storage: ~85 MB to 180 MB / day (100x lighter than Windows Recall's 25+ GB).
🔮 Level 6: Counterfactual Causal Simulation
CPU: ~4.0% 💾 24h Max: ~25 MB – 60 MB 🔒 Sovereign Temporal Sandbox
